# Femme Stalls

A women-led community platform from Kilakarai, Tamil Nadu, India — backed by Geohomz.

**Organise the Unorganised.**

## Tech Stack

- [Next.js 15](https://nextjs.org) (App Router, TypeScript, Turbopack)
- [Tailwind CSS](https://tailwindcss.com)
- [Shadcn/UI](https://ui.shadcn.com) on Radix primitives
- [Lucide](https://lucide.dev) icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — lint the codebase
